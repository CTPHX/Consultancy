# AVD Manager

*By Phoenix Software*

This folder contains the source code and supporting files for the AVD Manager web application.

## Version 1

Initial scope:
- Microsoft Entra ID sign-in
- First-run Azure discovery and onboarding
- Subscription and resource discovery
- AVD host pool discovery and environment mapping
- Dark theme by default with optional Light mode in Settings
- Dashboard overview
- Session host management and deployment
- Azure Automation job tracking
- Audit logging
- Environment configuration
- Basic licensing framework

The existing PowerShell automation remains in the sibling `Deploy` folder and will be integrated into the web application through Azure Automation.
